# An-Empirical-Fitts-Law-Study-on-Thumb-Touch-Performance-in-Single-Handed-Operation
This study examines motor control in commuters operating an iPhone 13 single-handedly with their right thumb. Large screens limit comfortable reach, forcing users to overextend or shift grips for edge UI. We apply Fitts' Law to quantify how these extreme distances and target sizes affect Movement Time.
